MONDAY privacy policy

Last updated 13 November 2026

MONDAY is a personal assistant used by one person, its owner, on their own computer. It is not a service offered to anyone else. This policy explains what MONDAY does with Google data.

What MONDAY accesses

  • Google Calendar events: to tell the owner what is scheduled, and to add or move events when the owner asks.
  • Gmail messages (read-only): to tell the owner about unread mail and find messages they ask about.
  • Gmail drafts: to write drafts the owner asks for. MONDAY has no function that sends email.

Where the data goes

MONDAY runs on the owner's computer. Google data is fetched only when the owner asks a question or opens the dashboard, and it is not stored on any server run by MONDAY: there is none. The Google sign-in token is kept in a file on that computer that only the owner's Windows account can read.

To answer a question, the relevant text may be sent to the AI model provider the owner has configured (currently OpenRouter, routing to Anthropic's Claude) under that provider's terms. Data is never sold, never used for advertising, and never shared with anyone else.

Google API Services User Data Policy

MONDAY's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke MONDAY's access at any time at myaccount.google.com/permissions, and can delete the local token file to remove the stored sign-in.

Contact

Questions about this policy go to the app owner through the support email shown on MONDAY's Google sign-in screen.
